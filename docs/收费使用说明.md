# 会员与收费使用说明

**中文** · [English](en/billing.md)

本说明补充现有机器人使用说明。所有购买、订单查询和管理员收费操作都在机器人私聊完成，不提供网页后台或支付回调监听服务。

附加包只向当前有效的普通周会员开放。附加额度永久保留，可叠加；会员到期不清零，但不能替代有效会员时间。月、季套餐期间目标不限，永久附加额度仍保留，未来转为周套餐时继续计算。

“目标”包括频道、群组和超级群组。用量是有效目标绑定与所有未删除任务有效目标的去重并集，同一目标在多个任务中只计算一次，消息来源不计入。只解绑不能消除仍在任务中的目标；需要同时解绑并从任务中移除，或删除对应任务。暂停、停止但未删除的任务目标仍计入。

商业额度不限不取消 Telegram API 限速、双方管理员要求、安全配额、队列容量或权限检查。实际发送仍受现有系统安全设置约束。

## 会员中心与续费

首页的“会员中心”显示当前套餐、当前开始与到期时间、排队订阅截止时间、永久附加额度和已用/上限。时间以界面标注的 UTC 为准。

订阅按确认入账顺序分段排队。新一段从“入账时当前时间”与“已购最后一段结束时间”中较晚者开始，完整增加所购天数，不重叠、不截断已有套餐。购买不同套餐不会立即改变当前套餐的权益；确认页的开始时间只是当时估计，以实际入账队列为准。

例如当前周套餐后续购买月套餐，剩余周套餐继续适用20个基础目标，月套餐到排队开始时才不限目标。月或季套餐结束后进入周套餐，若现有用量超过周套餐总额度，全部发布会被阻止，不会任意保留其中一部分目标。请先清理多余绑定和任务目标，再手动恢复。

会员到期或超额会暂停发布，保留已有资源、历史、游标和暂停剩余等待。购买、续费、补额度或关闭收费都不会自动恢复任务；应到任务详情检查后点击启动并确认。会员失效期间的即时来源消息不会在续费后自动补发。

没有有效会员时仍可查看和整理数据、保存内容草稿、解绑、移除任务目标、停止或删除任务、导出日志、购买和联系支持。新增目标或来源绑定、新建任务、测试目标发信、启动/恢复、立即发布和 UNKNOWN 重发需要通过实际资源所有者的会员与额度检查。管理员代普通用户操作，也不会借用管理员自身的永久豁免绕过用户门禁。

## 购买与订单

1. 打开“购买 / 续费”，选择套餐或当前可购买的附加包。
2. 阅读金额、完整时长、排队生效说明和购买条款，再点击“同意条款并创建订单”。未确认不会创建支付订单。
3. 订单处于等待付款状态且具有经过白名单校验的链接时，点击“前往 OKPay 付款”。付款链接仅允许官方 OKPay Telegram 入口，不接受自定义收款网址。
4. 返回“我的订单”，选择订单并点击“查询付款结果”。查询不会创建新订单。系统也会对待处理订单进行有限频率轮询；权益只在签名、商户、订单、币种和精确金额全部核验通过后一次性入账。
5. 入账后前往任务手动启动。不要把付款成功页面截图当成机器人已入账的依据。

同一购买确认的重复点击使用固定请求键，关联同一个本地订单。创建请求结果不明确时显示“创建结果待核实”，不会擅自再次创建支付请求；请保留原订单并联系支持，避免重复购买或付款。手动重新选择商品会进入新的购买流程，不是原订单重试。

订单页同时显示本地订单编号、商户订单号和OKPay平台订单号。正常订单为“等待付款”，点击绿色“前往 OKPay 付款”打开真实收款机器人入口；付款后系统自动检测并开通，无需管理员手动确认。查询按钮只是立即刷新结果。

其他状态包括创建处理中、创建结果自动核实中、已付款/已入账、支付入口自动恢复中、支付数据校验异常或创建失败。只有签名异常或金额、订单等字段不一致时才停止发放并提示联系支持。待处理订单不会仅因超时被删除；不确定结果请保留原订单联系支持。

如果原单仅因付款链接校验失败进入核对，查询付款结果会在两次官方签名查单均通过、两次状态均为未付款且平台订单一致后，恢复同一订单的官方付款链接；后台也会有限频率重查。此过程不重复调用创建接口，也不会发放未付款权益。其他人工核对原因不会自动解除。入口兼容官方账号名大小写，统一为官方收款链接，拒绝转账、提现、伪造域名或与平台订单不符的链接。请重新打开原订单，不要为找回按钮重复创建订单。

订单权益始终属于创建订单的本机器人用户。允许他人代付，但付款账号不会取代本地订单所属用户。普通用户只能查询自己的订单。

## 条款与支付风险

正常付款不退款，法律或平台强制要求、重复扣款及未履行服务的纠错除外。需要纠错请提供本地订单编号，不要发送支付密钥。

Telegram 数字服务可能受 Stars 政策限制。OKPay 是第三方支付渠道，不代表其获 Telegram 认可或符合所有地区、平台要求，存在账号限制、支付失败与服务中断风险。购买确认页会再次提示，购买前需自行确认接受。

联系支持：默认 `@sad1881`，如管理员修改了联系方式，以机器人“联系管理员”页面为准。

## 管理员收费管理

管理员权限与永久会员/商业额度豁免只来自服务端 `settings.admin_ids`。现有部署管理员为 `100000001` 和 `100000002`；移出配置后不再享有管理权限或豁免，用户名不会获得权限。管理员仍受封禁和发送安全规则约束。

入口为“管理员 → 收费管理”。可查看收费开关、收款配置状态、脱敏密钥展示、商户 ID 和订单状态数量；可按数字用户 ID 查询会员与订单，并通过二次确认调整权益。

### 收款配置

1. 服务端先配置有效的 `BILLING_ENCRYPTION_KEY`；由部署人员安全生成并保管。不要通过内容草稿、普通系统配置或聊天发送此服务端加密密钥，丢失会导致历史支付凭据无法解密。
2. 点击“收款配置”，先发送 OKPay 数字商户 ID，此步骤不要发送支付密钥。
3. 阅读密钥保管和轮换风险，再点击确认进入专用密钥输入状态。
4. 仅发送 OKPay 支付密钥，或发送 `/paytoken 密钥`。机器人会立即尽力删除这条 Telegram 消息；只在专用流程且管理员资格仍有效时进行无资金移动的余额查询验证，成功后才启用新配置。验证失败保留旧配置，界面不回显密钥或底层异常。
5. `/cancel` 退出并保留旧配置。向导超时、重启后只剩脱敏记录或提示重新发送时，重新打开配置流程。不要将敏感密钥混入普通正文；`/paytoken` 会在任何会话优先截获，不作为内容保存。

专用密钥状态只保存商户 ID 和随机 nonce，不保存明文支付密钥。原始更新入库前会脱敏；密钥只通过进程内存交给配置验证，数据库仅保存加密凭据。Telegram 删除是尽力而为，不能保证平台或客户端副本已清除。

轮换配置会保留旧加密凭据以查询历史未完成订单。若在 OKPay 停用旧密钥，旧订单可能无法继续核验；先处理历史未完成订单，再考虑外部停用。不要删除加密配置或历史凭据来“清理订单”。

### 收费开关与权益调整

启用/关闭收费均需二次确认。启用收费会在事务中暂停所有非管理员的运行任务，不删除资源、历史或任务游标。关闭收费也不会自动启动任何暂停任务。不要把开关当成批量恢复按钮。

查询用户后可选择“调整权益”，输入“天数 附加目标数 原因”，例如 `7 10 服务中断补偿`，再二次确认。原因必填，限300字；单次最多调整正负3650天或100000个永久目标。

正天数按不限商业目标的月会员分段追加；负天数从最新排队尾部扣减。永久目标可增加或扣减，但不能低于0。每次调整记录管理员、原因和调整数值，不会自动恢复任务。调整已入账权益不等于退款，不会自动转账、撤销支付或删除原订单。

封禁规则优先于会员与管理员豁免。被封禁用户不能通过付费、附加额度或管理员代操作恢复发布；须先按既有封禁流程解除封禁，再主动启动任务。

## 验证边界

项目自动化验证使用离线机器人替身、模拟支付响应和独立测试数据库，不进行真实付款、转账或生产广播。未进行真实小额支付闭环前，不应声称商户凭据或真实入账已验收。
