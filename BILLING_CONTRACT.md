# Billing upgrade contract

Billing module contract. Keep existing business data intact across the migration. No web server / callback listener. OKPay HMAC protocol: <https://docs.okaypay.me/doc.html>. Never print secrets or put payment tokens in sessions, raw updates, audit details, exceptions, or logs. Existing update persistence MUST redact secret-setting messages before durable insert.

## Ownership
- Parent: migrations/004_billing.sql, adbot/entitlements.py, engine.py, main.py, deployment/integration/docs. Do not edit others' files.
- Payment child: adbot/payments.py, tests/test_payments.py. Uses entitlement repository, no engine/UI edits.
- UI child: adbot/billing_ui.py, adbot/ui.py, tests/test_billing_ui.py, docs/收费使用说明.md. No payment/engine/DB migrations edits.

## Rules
- week: 7 days / 10 USDT / 20 distinct destinations; month: 30 days / 30 USDT / unlimited commercial destinations; quarter: 90 days / 66 USDT / unlimited. Unlimited usage counts within valid time; free API rates and safety configuration remain.
- extra10: 10 destinations / 3 USDT; extra50: 50 destinations / 10 USDT. Add-on quota is PERMANENT, survives subscription expiry. Only available with an active non-admin week segment. It does not add membership time. Same destination reused by tasks counts once. Destination means both channel/group. Do not count sources.
- Distinct quota is union of active user_chats bindings plus active targets in non-deleted tasks (so unbind cannot bypass). Over limit at plan downgrade blocks all publishing until user removes sufficient bindings/targets; never silently select some destinations. Read/manage/delete/stop/export/support/pay remain available without subscription; publishing/new binding/new task require active access. Content draft storage remains available.
- Subscription renewals are appended segments: starts_at=max(now, latest ends_at), ends_at=starts+days. Plan changes queue, never truncate/overlap or retroactively downgrade/upgrade existing paid time. Before pay, explain queued activation and duration. Expiry pauses, no auto resume after purchase. No automatic catch-up/replay of expired-time instant events.
- admins=settings.admin_ids are permanently exempt from membership and commercial quotas, but ban/security still applies. Charging defaults false in migration; parent explicitly enables at safe cutover, transaction pauses every non-admin RUNNING task and audits, preserving records/cursors. Do not restart admin or user tasks implicitly.
- User purchase terms state normal payments non-refundable except mandatory legal/platform requirements, duplicate charge or unfulfilled service corrections. Warn Telegram digital-service Stars policy, do not claim OKPay compliant. Show confirmation before create order.

## Parent entitlement API (no network, settings required)
class AccessDenied(ValueError).
